# Screen Translate Pro

crie o frontend para uma ferramenta semelhante a captura de tela, ao iniciar o software vai abrir uma janelinha semelhante a essa da ferramenta de captura, onde tem essa câmera seleciona vai ter a opção : fixo e ao lado captura de tela , ao selecionar fixo e clicar em novo, a ferramenta permite ao usuário selecionar uma área da tela e ao selecionar como mostra a terceira imagem ela vai delimitar, marcar aquela espaço com linhas pontilhadas, o menu que aparecia na segunda imagem continua mesmo após o usuário delimitar o espaço e ele só sairá ao clicar no botão de cancelar que é pra adicionar ao menu flutuante que o usuário poderá arrastar para qualquer parte da tela, mas caso o usuário escolha no menu antes de delimitar a tela por captura de tela e depois novo, ela vai capturar a tela e vai mostrar na tela o texto daquela área delimitada traduzido, mas se for fixo ele vai traduzir todo texto que aparecer na área delimitada até o usuário sair daquele modo pelo botão cancelar .
